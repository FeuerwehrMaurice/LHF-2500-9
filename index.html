2. Zweck der Anwendung

Die Web-Anwendung „Lehrfeuerwehr 2500 / LHF 2500/9“ dient der internen Dienst- und Fahrzeugbesetzungsplanung. Verarbeitet werden nur Daten, die für diese organisatorischen Funktionen benötigt werden.

3. Verarbeitete Daten

Je nach Nutzung können insbesondere folgende Daten verarbeitet werden:

  • Name der eingetragenen Person
  • Zugehörigkeit zur Wachabteilung
  • Verfügbarkeitsstatus für einen Dienst
  • zugeteilte Fahrzeugfunktion bzw. Besetzung
  • Dienst-, Planungs-, Historien- und Statistikdaten
  • technische Verbindungsdaten, die beim Aufruf oder bei der Authentifizierung anfallen

Die Anwendung ist nicht dafür vorgesehen, besondere Kategorien personenbezogener Daten nach Art. 9 DSGVO zu erfassen. Insbesondere sollen keine Diagnosen oder sonstigen Gesundheitsdetails eingetragen werden. Für die Planung genügt ein neutraler Verfügbarkeitsstatus.

4. Lokaler Browser-Speicher

Die Anwendung verwendet LocalStorage und SessionStorage des Browsers, um technisch notwendige Zustände wie die gewählte Wachabteilung, Planungsstände, lokale Einstellungen und Sitzungsinformationen zu speichern. Diese Speicherung dient der vom Nutzer aufgerufenen App-Funktion. Es werden derzeit keine Werbe- oder Tracking-Cookies eingesetzt.

5. Firebase / Google

Für die geräteübergreifende Synchronisierung werden Google Firebase, insbesondere Cloud Firestore und Firebase Authentication, eingesetzt. Die Firebase-Anmeldung erfolgt derzeit anonym; Nutzer müssen dafür keine persönliche E-Mail-Adresse hinterlegen. In Cloud Firestore können die für die Anwendung benötigten Personal-, Dienst-, Besetzungs-, Historien- und Statistikdaten gespeichert werden.

Bei Firebase Authentication können insbesondere IP-Adresse und User-Agent zur Absicherung und Missbrauchsvermeidung verarbeitet werden. Firebase Authentication wird nach Angaben von Google aus Rechenzentren in den USA betrieben. Cloud Firestore nutzt Google-Infrastruktur und kann abhängig von der gewählten Projektregion verarbeitet werden.

6. Hosting über GitHub Pages

Die Web-Anwendung wird derzeit über GitHub Pages bereitgestellt. GitHub protokolliert beim Besuch einer GitHub-Pages-Website die IP-Adresse des Besuchers zu Sicherheitszwecken. Dabei können darüber hinaus technisch notwendige Verbindungsdaten verarbeitet werden.

7. Empfänger und Dienstleister

Empfänger bzw. Auftragsverarbeiter können im Rahmen des technischen Betriebs insbesondere GitHub für das Hosting sowie Google für Firebase-Dienste sein. Eine Weitergabe an Werbenetzwerke oder Datenhändler ist durch die Anwendung nicht vorgesehen.

Soweit hierfür erforderlich, stützt sich die Verarbeitung auf die von Google für seine Dienste vorgesehenen datenschutzrechtlichen Garantien. Welche Garantie im Einzelfall einschlägig ist, richtet sich nach dem für das Firebase-Projekt geltenden Vertrags- und Produktstatus.

Für eine produktive Nutzung sollte eine konkrete Löschfrist für Historien- und Statistikdaten festgelegt werden.
